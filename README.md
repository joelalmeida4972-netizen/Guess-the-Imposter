## 🎯 The Core Premise

Everyone in the room receives the **same secret word**—except for the **Imposter(s)**[cite: 1].

* **Regular Players:** Know the word[cite: 1]. Give clues that are subtle enough to show you're in the loop without giving the word away to the listener[cite: 1]!
* **The Imposter:** Has no clue what the word is, but gets a discrete **one-word topic clue**[cite: 1]. Listen like an eagle, bluff your turn, and avoid being voted out[cite: 1]!

---

## 🕹️ How It Plays Out

| Step | Phase | Action |
| :--- | :--- | :--- |
| **01** | **Setup** | Pick total players (3 to 22) and imposter count (1 to 10)[cite: 1]. Type names[cite: 1]. |
| **02** | **Secret Hand-Off** | The game randomizes the player sequence[cite: 1]. Pass the phone as each name is called[cite: 1]. |
| **03** | **Role Reveal** | Regular players read the secret word[cite: 1]. Imposters see their red alert badge with a subtle topic clue[cite: 1]. |
| **04** | **Hint Round** | A randomly selected player starts[cite: 1]. Everyone gives one clue around the circle[cite: 1]. |
| **05** | **The Vote** | The room debates, points fingers, and votes on who is bluffing[cite: 1]! |
| **06** | **Last Chance** | Caught imposter? Guess the exact word to steal victory from the jaws of defeat[cite: 1]! |

## ✨ Standout Features

* 📱 **Single-Phone Experience:** Runs completely offline or online on any mobile browser without requiring everyone to install an app[cite: 1].
* 🎲 **Anti-Metagame Shuffling:** Role reveals and discussion starters are picked through random permutations, meaning you can never predict an imposter by seat or turn order[cite: 1].
* 🧠 **Nearly 200 Curated Words:** From everyday items to challenging concepts (*Submarine*, *Black Hole*, *Chameleon*, *Espresso*), each paired with a calibrated hint.
* 🌗 **Theme Engine:** Default dark high-contrast theme built for nighttime and party lighting, with a clean light-mode toggle[cite: 1].
* ✍️ **Smooth Mobile Interaction:** Anti-glitch inputs for clean name entries and uninterrupted final imposter guesses[cite: 1].
